# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.1] - 2026-10-10

### Changed
- The App Store lists the plugin as "Freeboard Companion Apps".

## [1.0.0] - 2026-10-10

### Added
- Show Signal K webapps or web pages beside the chart of a plotter-extension
  chartplotter such as Freeboard-SK: in floating windows over the chart, or in
  its side panel.
- App Manager in the side panel: add, edit and delete apps; open, close, hide
  and show their windows.
- Per app: what it shows (an installed webapp with an optional extra path, or a
  web page), where it opens, what closing it does (*Unload* or *Hide*), whether
  a window opens at startup (*Always open*, *Remember last*, *Never open*), and
  an optional toolbar button.
- A navigation bar in the side panel that steps through the App Manager and
  the side-panel apps, with a shortcut back to the App Manager.
- Replaces Freeboard-SK's built-in Instruments drawer.
